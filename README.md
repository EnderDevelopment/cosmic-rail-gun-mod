# Cosmic Rail Gun Mod

A powerful rail gun mod for Minecraft that can one-shot the Ender Dragon.

## Features

- Adds a powerful rail gun item that can one-shot the Ender Dragon
- Creates big holes in the world when used

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the mod file (`.jar`).
2. Place it in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

1. Craft or obtain the Cosmic Rail Gun item.
2. Right-click to fire the rail gun.
3. Enjoy the power of the cosmic rail gun!

## Configuration

No additional configuration is needed. The mod works out of the box.
